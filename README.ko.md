# Hush

[English](README.md) · **한국어**

**광고와 팝업, 방해 요소 없이 조용하게 웹을 둘러보세요.**

Hush는 화면 전체를 페이지에 내주고, 거슬리는 것은 탭 한 번으로 숨겨 사이트 전체에서 기억하는
Android 브라우저입니다. 시스템 WebView 위에서 동작하며, 계정이 필요 없고 분석·광고 SDK도 들어
있지 않습니다.

Android 7.0 이상 · 10개 언어 · 라이트·다크 모드

---

## 한눈에 보기

- **화면은 페이지의 것.** 읽는 동안 주소창이 비켜나고, 사이트 이름이 적힌 얇은 띠만 남습니다.
  띠를 탭하면 주소창이 돌아오고, 아예 전체 화면으로 볼 수도 있습니다.
- **한 번 숨기면 끝.** 광고, 배너, 따라다니는 상자를 탭하면 그 사이트의 모든 페이지에서
  사라집니다.
- **처음부터 광고·추적 차단.** 필요하면 필터 목록을 더할 수 있습니다.
- **끊김 없는 YouTube.** 광고는 건너뛰고, 백그라운드에서도 계속 재생되며, 멈춘 곳에서 다시
  열립니다. 모든 동영상을 정해 둔 속도와 화질로 재생하고, 원하면 스폰서 구간을 건너뛰며
  Shorts도 숨깁니다.
- **개인정보 보호가 기본.** 링크의 추적 코드를 지우고, Global Privacy Control을 보내며,
  시크릿 탭은 흔적을 남기지 않는 별도 프로필에서 동작합니다.
- **비밀번호 관리자.** 휴대전화 안에서 암호화하고, 맞는 사이트에만 채워 넣습니다.

## 기능

### 웹 둘러보기

- **비켜나는 주소창**: 위나 아래에 둘 수 있습니다(설정 › 모양 › 주소창). 페이지 안의 스크롤
  상자를 움직여도 따라 숨고, 사이트가 메뉴나 대화상자 때문에 스크롤을 막으면 다시 나타납니다.
- **전체 화면**: 메뉴에서 켜고, 모서리 버튼이나 뒤로 가기로 나옵니다.
- **간결한 주소**: `https://www.naver.com/news` 대신 `naver.com/news`로 보여 줍니다. 주소를
  고칠 때는 전체 주소가 나오고, "전체 웹 주소 표시"를 켜면 항상 전체 주소를 보여 줍니다.
- **제스처**: 주소창을 옆으로 밀면 탭이 바뀌고, 페이지를 아래로 당기면 새로고침됩니다.
  페이지 왼쪽·오른쪽 가장자리에서 안쪽으로 밀면 뒤로·앞으로 가고, 알림은 옆으로 밀어 닫습니다.
- **검색엔진**: Google이나 네이버, 또는 검색 결과 주소(검색어 자리에 `%s`)를 넣어 추가한 어떤 사이트든.
- **추천 검색어**: 북마크, 방문 기록, 열린 탭, Google이나 네이버에서 가져옵니다. 시크릿 탭에서는
  보내지 않고, 직접 추가한 검색엔진으로도 보내지 않습니다.
- **시작 페이지**: 새 탭에는 검색창과, 카드에 모은 자주 가는 사이트가 각 사이트의 아이콘과 함께
  나옵니다. 시크릿 탭에서는 사이트 대신 무엇이 남지 않고 누가 여전히 볼 수 있는지 알려 줍니다.
- **런처 바로가기**: 앱 아이콘을 길게 누르면 "새 탭"과 "새 시크릿 탭"이 나옵니다.
- **Hush로 공유**: 어느 앱에서든 공유하면 그 안의 링크가 추적 코드 없이 새 탭에서 열립니다.
- **더 안전한 기본값**: `http` 링크는 먼저 `https`로 열고, 사이트가 `https`를 제대로 지원하지
  않을 때만 다른 브라우저처럼 `http`로 엽니다. 페이지를 열 수 없으면 이유와
  다음에 할 일을 알려 주고, 인터넷이 다시 연결되면 저절로 다시 불러옵니다. 주소창에는 열려던
  주소가 그대로 남아, 고쳐서 다시 열 수 있습니다.
- **길게 누르기 메뉴**: 링크, 이미지, 전화번호, 이메일, 주소마다 알맞은 동작을 보여 줍니다.

### 거슬리는 것 숨기기

- **메뉴 › 숨길 영역 선택**을 누르고 숨길 곳을 탭합니다. *크게*와 *작게*로 알맞은 상자를 고르고,
  저장하기 전에 규칙이 숨길 곳이 모두 표시됩니다. 고르는 동안에는 페이지가 이동하거나 창을 열 수
  없어서, 광고를 탭해도 안전합니다.
- **규칙은 사이트 전체에 적용**됩니다(`www.`는 무시). 필요하면 특정 페이지에서만 끌 수 있습니다.
- **주소가 자주 바뀌는 사이트**(name42.com, 다음엔 name43.org)는 규칙 목록 하나를 함께 쓸 수
  있습니다.
- **숨기기 규칙**(설정 › 광고 차단): 모든 사이트의 규칙을 한곳에서 봅니다. 선택자를 고치거나,
  규칙을 모든 페이지에서 끄거나, 한 사이트의 규칙을 공유하거나, 전체를 파일 하나로 내보내고
  가져올 수 있습니다.

### 광고·추적 차단

- **기본 제공**: 알려진 광고 서버를 막고 흔한 광고 영역을 숨깁니다. 처음 실행할 때부터 켜져 있습니다.
- **필터 목록**: 직접 고를 때만 켜집니다. EasyList, EasyPrivacy, List-KR, EasyList Cookie
  List를 HTTPS로 받아 5일마다 새로 고칩니다.
- **쿠키 배너**: 주요 동의 플랫폼의 배너를 숨기고, 배너 때문에 멈춘 스크롤을 풀어 줍니다.
- **팝업 및 페이지 강제 이동 차단**: 탭하지 않았는데 뜨는 창은 막고 열 수 있는 선택지를 남기며,
  페이지가 몰래 다른 페이지로 바뀌지 못하게 합니다.
- **사이트별 일시중지**: 주소창의 방패에서 끌 수 있고, 차단한 개수도 그곳에서 보여 줍니다.
- 차단된 주소로 가면 "Hush가 이 페이지를 차단했습니다"와 함께 **그래도 열기**가 나옵니다.

### YouTube

- **YouTube 광고 건너뛰기**: 플레이어가 보기 전에 영상 데이터에서 광고 구간을 빼냅니다. 그래도
  나오는 광고는 소리를 끄고 빠르게 재생하다가, 실제 탭으로 건너뜁니다.
- **백그라운드에서 YouTube 계속 재생**: PIP 모드에서도, 화면이 꺼져도 계속 재생됩니다.
- **YouTube 이어서 보기**: 탭을 다시 열면 멈춘 곳에서 "이어서 보기" 카드와 함께 열립니다.
  재생 버튼을 누를 때까지 대기, 이어폰이 연결돼 있으면 바로 재생, 항상 바로 재생, 사용 안 함
  중에서 고릅니다.
- **YouTube Shorts**: 피드와 검색의 Shorts, Shorts 버튼, 채널의 Shorts 탭을 각각 스위치로
  숨깁니다. Shorts 링크는 그대로 열립니다.
- **속도와 화질**: 모든 동영상이 정해 둔 재생 속도로, 정해 둔 최고 화질로 시작합니다. 화질은
  Wi-Fi와 모바일 데이터에서 따로 고르며, 로그인하지 않아도 됩니다.
- **스폰서 구간 건너뛰기**: SponsorBlock을 켜면 스폰서 광고, 구독 요청, 인트로 등 고른 구간을
  건너뛰고, 실행취소로 다시 볼 수 있습니다. 기본은 꺼져 있습니다. SponsorBlock 서버에는 동영상
  ID로 만든 코드의 앞 네 글자만 보내며, 이 네 글자는 수천 개의 동영상이 함께 씁니다.
- **YouTube 앱에서 바로**: 공유 › Hush를 고르면 그 동영상이 여기서 열립니다.

### 동영상과 소리

- **PIP 모드**: 동영상을 재생하다 앱을 나가면 작은 창으로 이어지고, 페이지 안의 동영상은
  메뉴에서 띄울 수 있습니다. 창에서 **소리만 재생**으로 바꿀 수 있습니다. 화면에 보이지 않는
  동안 YouTube는 재생하던 화질을 그대로 유지해, 다시 보면 두고 간 화질 그대로 이어집니다.
- **화면이 꺼져도 계속 재생**: 잠금 화면에 재생 컨트롤과 진행 막대가 나옵니다. 10초 뒤로·앞으로
  갈 수 있고, 페이지에 이전·다음이 있으면 그것도 나옵니다.
- **수면 타이머**: 메뉴에서 15~90분 뒤나 동영상이 끝날 때 멈추게 합니다. 멈추기 전에 소리가
  서서히 줄어듭니다.
- **이어폰 연결 종료 시 일시중지.**

### 개인정보와 보안

- **시크릿 탭**은 시스템 WebView가 지원하면 쿠키·저장소·캐시가 분리된 별도 프로필에서 동작하고,
  마지막 시크릿 탭을 닫으면 비워집니다. 방문 기록과 저장된 세션에 남지 않으며, 허용하지 않는 한
  화면을 캡처할 수 없습니다. 시크릿 탭이 열려 있는 동안에는 **시크릿 탭 모두 닫기** 알림을 탭해
  한 번에 닫을 수 있고, 이 알림은 잠금 화면에 나오지 않습니다.
- **링크에서 추적 코드 제거**: 공유하거나 복사하거나 다른 사이트로 따라가는 링크에서 `utm_*`와
  클릭 ID를 지웁니다.
- **사이트에 개인정보 판매·공유 거부 요청**: Global Privacy Control을 보냅니다.
- **사이트 정보**: 연결이 안전한지, 인증서의 모든 내용(발급자, 유효 기간, 이름, 지문), 그리고
  그 사이트의 숨기기 규칙과 권한을 보여 줍니다.
- **필요할 때만 묻는 권한**: 카메라, 마이크, 위치는 사이트마다 묻고, Android 권한은 허용한
  사이트가 실제로 필요로 할 때만 요청합니다.
- 서드파티 쿠키는 꺼져 있고, `https` 페이지는 평문 HTTP로 아무것도 불러오지 않습니다. **인터넷 사용 기록 삭제**로 방문 기록, 쿠키와
  사이트 데이터, 캐시를 지웁니다.

### 비밀번호

- 로그인하면 **저장**을 제안하고(시크릿 탭에서는 하지 않음), "○○(으)로 로그인하시겠습니까?"를
  탭하면 **채워 넣습니다**.
- **자동 채우기**: 저장된 로그인이 하나뿐인 HTTPS 사이트에서, 비어 있는 칸에만 채웁니다.
- **강력한 비밀번호 생성기**: 길이 8–64자, 문자 종류, 헷갈리는 글자 빼기를 고를 수 있습니다.
- **비밀번호 화면**: 추가할 수 있고, 보기와 복사는 화면 잠금을 거쳐야 하며, 스크린샷을 찍을 수
  없습니다.
- AES-256-GCM으로 암호화하고, 휴대전화가 잠금 해제되어 있을 때만 쓸 수 있는 Android 키 저장소의
  키를 씁니다. 백업에도 포함되지 않습니다. 비밀번호는 페이지가 주장하는 사이트가 아니라 WebView가
  알려 주는 사이트에만 저장되고 채워집니다.

### 탭과 보관함

- **탭 전환 화면**: 탭마다 페이지 미리보기가 보이고, 밀어서 닫고(실행 취소 가능), 끌어서 순서를
  바꿉니다. 시크릿 탭은 따로 모아 둡니다.
- **최근에 닫은 탭**, 그리고 탭을 닫은 직후의 실행 취소.
- **탭 복원**: 다음에 실행할 때 탭이 돌아오고, 시작할 때는 앞에 있는 탭만 불러옵니다.
- **방문 기록**: 날짜별로 보고 검색할 수 있습니다.
- **북마크**: 검색, 편집, 끌어서 순서 바꾸기를 지원하고, 표준 북마크 파일로 내보내고 가져옵니다.
- **다운로드**: 페이지가 파일을 저장하기 전에 먼저 묻고, 진행 상황과 열기, 다시 시도를 보여 줍니다.

### 읽기와 페이지 도구

- **읽기 모드**와 **소리 내어 읽기**.
- **페이지에서 찾기.**
- **화면 캡처**: 보이는 부분이나 페이지 전체를 저장하거나 공유합니다.
- **텍스트 크기**: 모든 사이트에, 또는 메뉴에서 사이트마다 따로 정합니다.
- 탭마다 **데스크톱 사이트**, **홈 화면에 추가**, **인쇄 또는 PDF로 저장**.

### 나에게 맞게

- **라이트·다크 모드**나 시스템 설정을 따르기, 그리고 **모든 사이트 어둡게 표시**.
- **다섯 가지 테마**: 클래식, 톤 컬러, 블루, 앱 아이콘, 글래스.
- **10개 언어**: English, 한국어, 日本語, 简体中文, 繁體中文, Español, Français, Deutsch,
  Português, Русский. 휴대전화 언어를 따르거나, Hush에서만 쓸 언어를 고를 수 있습니다.
- **홈페이지, 새 탭 페이지**, 홈 버튼을 원하는 대로.
- 환영 화면이나 설정에서 **기본 브라우저로 설정**.

## 내려받기

**[Hush 1.3.2](releases/1.3.2/Hush-1.3.2.apk)** · 3.4 MB · Android 7.0 이상 ·
[새로운 점](CHANGELOG.md)

1. 휴대전화에서 APK를 내려받아 엽니다.
2. Android가 물으면 브라우저나 파일 앱에 '출처를 알 수 없는 앱 설치'를 허용합니다.
3. 업데이트는 쓰던 버전 위에 설치되고, 탭과 북마크, 비밀번호가 그대로 남습니다.

PIP 모드는 Android 8.0, 런처 바로가기는 Android 7.1부터 쓸 수 있습니다.

### 내려받은 파일 확인

모든 버전은 같은 키로 서명됩니다. Android는 다른 키로 서명된 업데이트를 거부하므로, Hush 위에
설치되는 APK는 여기서 나온 것입니다.

- APK SHA-256: `56ace010a83ce8cb7954798c72097ad374ae2ef014a52c25b4d610b71567494e`
- 서명 인증서 SHA-256: `00:37:AE:C5:11:EF:6B:A7:37:50:6D:24:BD:AC:64:54:04:EE:37:1E:F1:F1:4D:F2:4A:FC:B6:5F:D3:67:8E:52`

```sh
shasum -a 256 Hush-1.3.2.apk
apksigner verify --print-certs Hush-1.3.2.apk
```

계정도, 분석 도구도, 광고 SDK도 없습니다. 휴대전화에 무엇이 남고 어디로 무엇이 전송되는지는 앱의
설정 › 정보 › 개인정보처리방침에 있습니다.
