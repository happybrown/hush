# Hush

[English](README.md) · **한국어**

**광고와 방해 요소 없이, 화면을 넓게 쓰는 Android 브라우저.**

거슬리는 것은 탭 한 번으로 숨기고, 사이트 전체에서 기억합니다. 계정이 필요 없고 분석·광고 SDK도
없습니다.

## 주요 기능

- **넓은 화면** — 읽는 동안 주소창이 작은 노치로 접혀 페이지가 화면 끝까지 보입니다.
- **탭 한 번으로 숨기기** — 광고나 배너를 누르면 그 사이트의 모든 페이지에서 사라집니다.
- **광고·추적 차단** — 처음부터 켜져 있습니다.
- **편한 YouTube** — 광고는 건너뛰고, 화면이 꺼져도 계속 재생되며, 멈춘 곳에서 이어서 볼 수 있습니다.
- **개인정보 보호** — 링크의 추적 코드를 지우고, 시크릿 탭은 흔적을 남기지 않습니다.
- **비밀번호 관리자** — 휴대전화 안에 암호화해 보관하고, 맞는 사이트에만 채웁니다.
